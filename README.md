# DealExit

منصة أولية لعرض وشراء المشاريع القائمة.

## تشغيل محلي

1. أنشئ قاعدة بيانات باسم `dealexit` ثم استورد ملف المخطط الأصلي `database/dealexit.sql`.
2. عدّل متغيرات البيئة `DB_HOST` و`DB_NAME` و`DB_USER` و`DB_PASSWORD` إن لم تكن إعدادات XAMPP المحلية الافتراضية مناسبة.
3. افتح `http://localhost/unit20/DealExit/capstone-project/`.

لا تحفظ أي كلمات مرور فعلية أو إعدادات إنتاجية داخل المستودع.
